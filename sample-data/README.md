# Sample data: network engineer starter pack

`network-engineer-starter.zip` is a ready-made backup for Tools Manager: **322 shortcuts in 20 categories**,
with icons already included.

## How to use it
1. Start Tools Manager.
2. Open the menu and choose **Backup / Restore**: in XP use the Start menu's right pane, in Windows 98 + 8 use **Settings**.
   Pick **Restore (ZIP)...** and select `network-engineer-starter.zip`.
3. Confirm. **Restore replaces everything you currently have**, so use **Backup (ZIP)...** first if you want to keep your own list.

Eight shortcuts (ChatGPT, Claude, Google, diagrams.net, Cisco Support, MXToolbox, Visual Subnet Calculator, Wireshark Wiki)
are pinned to the desktop. Right-click one and choose **Remove from desktop** if you don't want them there.

## Good to know
- Some sites need a login (Cisco, Meraki, cloud consoles, Outlook/Teams). The shortcut opens the sign-in page.
- Your company web filter may block a few sites. Two were removed because they were blocked when this list was built.
  If a shortcut opens a block page, delete it or edit its URL.
- Two shortcuts (SONiC, Palo Alto Beacon) have no site icon and show a letter tile. Use Edit to set an icon image.
- URLs were checked on 2026-10-29. Websites change, so use **Edit...** to fix any that moved.
